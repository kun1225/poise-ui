## Usage

```tsx
import { Slider, SliderLabel, SliderValue } from "@/components/ui/slider";

<Slider defaultValue={24} min={0} max={40} name="radius">
  <SliderLabel>Corner Radius</SliderLabel>
  <SliderValue />
</Slider>;
```

Children render inside the card row.
Use `SliderLabel` on the left.
Use `SliderValue` on the right.

Pass one or two values.
Two values render a range.
The slider is horizontal only.

## Options

Added props:

| Prop         | Default | Effect                                                       |
| ------------ | ------- | ------------------------------------------------------------ |
| `elastic`    | `true`  | Whether the edge gives when a thumb is dragged past it.      |
| `elasticCap` | `0.25`  | Maximum elastic distance as a fraction of the control width. |

### elastic

<ComponentPreview name="slider-rigid" />

Reduced motion disables elastic movement.

Use `elasticCap` to limit edge movement.
Lower values feel stiffer.
