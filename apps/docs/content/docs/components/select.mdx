## Usage

```tsx
import {
  Select,
  SelectContent,
  SelectItem,
  SelectTrigger,
} from "@/components/ui/select";

<Select defaultValue="smooth" name="spring">
  <SelectTrigger placeholder="Pick a spring" />
  <SelectContent>
    <SelectItem value="snappy">Snappy</SelectItem>
    <SelectItem value="smooth">Smooth</SelectItem>
  </SelectContent>
</Select>;
```

`SelectTrigger` renders the value and the chevron for you, so it takes no
children. Every `SelectItem` needs a `value`; give the root a `name` to submit
one with a form.

An item whose children are not a string cannot be shown on the trigger or
matched by typeahead. Pass `label` on those items to say what the text is.

## Options

Beyond Base UI's own props:

| Component       | Prop                   | Default     | Effect                                             |
| --------------- | ---------------------- | ----------- | -------------------------------------------------- |
| `SelectTrigger` | `placeholder`          | `"Select…"` | Shown until something is selected.                 |
| `SelectContent` | `side`                 | `"bottom"`  | Which edge of the trigger the popup opens from.    |
| `SelectContent` | `align`                | `"start"`   | How the popup lines up along that edge.            |
| `SelectContent` | `sideOffset`           | `6`         | Pixels between the trigger and the popup.          |
| `SelectContent` | `alignItemWithTrigger` | `false`     | Opens over the trigger, selected item on its text. |
| `SelectContent` | `positionerClassName`  | —           | Classes for the positioner, which owns z-index.    |

### placeholder

`placeholder` is what the trigger shows until something is selected, dimmed by
the `data-placeholder` Base UI puts on the trigger. The preview at the top of
this page starts empty, so it is showing one.

### side, align and sideOffset

`side` picks the edge of the trigger the popup opens from, `align` lines it up
along that edge, and `sideOffset` is the pixels between the two. The popup
grows from whichever edge it landed on, and flips to the opposite side when
there is no room.

<ComponentPreview name="select-placement" />

`alignOffset` shifts the popup along that same edge and passes straight through
to Base UI, which is why it is not in the table above.

### alignItemWithTrigger

Turn it on and the popup opens _over_ the trigger, positioned so the selected
item's text lands on the trigger's own text — the native `<select>` behaviour.
Base UI drives the popup's height itself in that mode, which is why the popup
drops its own `max-height` and its open transition when it is active.

<ComponentPreview name="select-align-item" />

It defaults to `false`, unlike Base UI, so that `side` and `align` work as the
table says. Turning it on **ignores both of them**, along with `sideOffset`.

Base UI also drops back to ordinary positioning on its own, in three cases: the
popup was opened by touch, the trigger is within 20px of the top or bottom of
the viewport, or there is too little room left to align without squashing the
popup. `min-height` on the positioner is what sets "too little" — a smaller one
falls back less often:

```tsx
<SelectContent alignItemWithTrigger positionerClassName="min-h-16">
```

Style the two modes apart with `data-side`, which is `"none"` while align mode
is the one in effect.

### positionerClassName

The positioner sits between the portal and the popup and owns z-index, so a
popup that lands behind something else is fixed there rather than on
`className`, which styles the popup itself.

```tsx
<SelectContent positionerClassName="z-100">
```

### Groups

Group related items and separate the groups. Every group needs its own
`SelectGroupLabel` inside it — that is what Base UI reads to label the group.

<ComponentPreview name="select-groups" />

### Scrolling

The popup is never taller than 18rem or the space actually available on the
side it landed on, whichever is smaller, and scrolls past that. Arrows appear
at whichever end has more list to reach.

## Anatomy

```text
Select               Base UI Select.Root
  SelectTrigger        Base UI Select.Trigger + Select.Value + Select.Icon
  SelectContent        Base UI Select.Portal + Select.Positioner + Select.Popup + Select.List
    SelectGroup        Base UI Select.Group
      SelectGroupLabel Base UI Select.GroupLabel
    SelectItem         Base UI Select.Item + Select.ItemIndicator + Select.ItemText
    SelectSeparator    Base UI Select.Separator
```

`SelectContent` is four Base UI parts in one, because none of them is useful
on its own and the popup has to sit inside all four to be positioned at all.
The checkmark sits in an absolute slot rather than the item's flex row, so a
row gaining or losing it never resizes the popup.
