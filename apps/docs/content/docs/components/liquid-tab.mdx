## Usage

```tsx
import {
  LiquidTabs,
  LiquidTabsList,
  LiquidTabsPanel,
  LiquidTabsTrigger,
} from "@/components/ui/liquid-tab";

<LiquidTabs defaultValue="overview">
  <LiquidTabsList>
    <LiquidTabsTrigger value="overview">Overview</LiquidTabsTrigger>
    <LiquidTabsTrigger value="settings">Settings</LiquidTabsTrigger>
  </LiquidTabsList>

  <LiquidTabsPanel value="overview">Overview panel content.</LiquidTabsPanel>
  <LiquidTabsPanel value="settings">Settings panel content.</LiquidTabsPanel>
</LiquidTabs>;
```

## Options

`LiquidTabsTrigger` takes an icon; `LiquidTabs` says how icons behave.

| Prop           | Default    | Effect                                   |
| -------------- | ---------- | ---------------------------------------- |
| `icon`         | —          | Node drawn beside the trigger's label.   |
| `icons`        | `"active"` | `"all"` shows every icon instead of one. |
| `iconPosition` | `"start"`  | `"end"` puts the icon after the label.   |

## Anatomy

```text
LiquidTabs              Base UI Tabs.Root
  LiquidTabsList          Base UI Tabs.List
    <pill>                  Stretches between the old and new active tab
    LiquidTabsTrigger       Base UI Tabs.Tab
      <content>               Icon and label, shifted so the label reads centred
      <highlight>             The same content again, clipped to the pill
  LiquidTabsPanel         Base UI Tabs.Panel
```

The icon never changes the tab's width - it only scales, fades and blurs, and
the label translates past it. The pill measures tab boxes, so a tab resizing
mid-travel would reach it as a resize and snap it to its target.
