---
title: Morph Select
description: A select whose list grows out from behind the trigger and welds itself to the edge it came from.
---

<ComponentPreview name="morph-select" />

## Usage

```tsx
import {
  MorphSelect,
  MorphSelectContent,
  MorphSelectItem,
  MorphSelectTrigger,
} from "@/components/ui/morph-select";

<MorphSelect defaultValue="smooth" name="spring">
  <MorphSelectTrigger placeholder="Pick a spring" />
  <MorphSelectContent>
    <MorphSelectItem value="snappy">Snappy</MorphSelectItem>
    <MorphSelectItem value="smooth">Smooth</MorphSelectItem>
  </MorphSelectContent>
</MorphSelect>;
```

## Options

Added props:

| Component            | Prop                  | Default     | Effect                                               |
| -------------------- | --------------------- | ----------- | ---------------------------------------------------- |
| `MorphSelectTrigger` | `placeholder`         | `"Select…"` | Shown until something is selected.                   |
| `MorphSelectContent` | `side`                | `"bottom"`  | Which edge of the trigger the popup grows from.      |
| `MorphSelectContent` | `sideOffset`          | `6`         | Pixels the popup comes to rest clear of the trigger. |
| `MorphSelectContent` | `positionerClassName` | —           | Classes for the positioner, which owns z-index.      |

### placeholder

Shown until an item is selected.

### side

Controls which edge the popup grows from.
The popup flips when space is limited.

<ComponentPreview name="morph-select-side" />

### sideOffset

Controls the final distance from the trigger.
Set it to `0` to keep both edges joined.

### positionerClassName

Sets classes on the positioner.
Use it for z-index changes.

```tsx
<MorphSelectContent positionerClassName="z-100">
```
