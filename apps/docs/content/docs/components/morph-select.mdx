## Usage

```tsx
import {
  MorphSelect,
  MorphSelectContent,
  MorphSelectItem,
  MorphSelectTrigger,
} from "@/components/ui/morph-select";

<MorphSelect defaultValue="smooth" name="spring">
  <MorphSelectTrigger placeholder="Pick a spring" />
  <MorphSelectContent>
    <MorphSelectItem value="snappy">Snappy</MorphSelectItem>
    <MorphSelectItem value="smooth">Smooth</MorphSelectItem>
  </MorphSelectContent>
</MorphSelect>;
```

## Options

Beyond Base UI's own props:

| Component            | Prop                  | Default     | Effect                                               |
| -------------------- | --------------------- | ----------- | ---------------------------------------------------- |
| `MorphSelectTrigger` | `placeholder`         | `"Select…"` | Shown until something is selected.                   |
| `MorphSelectContent` | `side`                | `"bottom"`  | Which edge of the trigger the popup grows from.      |
| `MorphSelectContent` | `sideOffset`          | `6`         | Pixels the popup comes to rest clear of the trigger. |
| `MorphSelectContent` | `positionerClassName` | —           | Classes for the positioner, which owns z-index.      |

### placeholder

`placeholder` is what the trigger shows until something is selected, dimmed by
the `data-placeholder` Base UI puts on the trigger. The preview at the top of
this page starts empty, so it is showing one.

### side

`side` is which edge of the trigger the popup grows from, and the trigger welds
that edge while the popup is still behind it. It flips to the opposite side when
there is no room, and the trigger follows the side the popup actually landed on
rather than the one it asked for.

<ComponentPreview name="morph-select-side" />

### sideOffset

`sideOffset` is where the popup comes to rest, not where it starts. It starts
behind the trigger either way, and the offset is the distance it travels clear —
so raising it makes the popup fly further, not just sit further away.

Set it to `0` and the popup stops with its edge against the trigger's, and the
two stay welded as one panel rather than parting.

### positionerClassName

```tsx
<MorphSelectContent positionerClassName="z-100">
```
