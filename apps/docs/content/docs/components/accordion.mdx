## Usage

### React

```tsx
import {
  Accordion,
  AccordionItem,
  AccordionPanel,
  AccordionTrigger,
} from "@/components/ui/accordion";

<Accordion defaultValue={["overview"]}>
  <AccordionItem value="overview">
    <AccordionTrigger>Overview</AccordionTrigger>
    <AccordionPanel>Panel content.</AccordionPanel>
  </AccordionItem>
</Accordion>;
```

Give every `AccordionItem` a `value`.
Use that value to control open items.

## Options

### React

`AccordionPanel` adds one prop.

| Prop     | Default  | Effect                                          |
| -------- | -------- | ----------------------------------------------- |
| `reveal` | `"none"` | `"stagger"` fades the panel's children in turn. |

<ComponentPreview name="accordion-stagger" />

`reveal="stagger"` only affects element children.
Reduced motion disables staggered fades.

### Web Component

| Element                | Attribute or property | Default | Effect                                  |
| ---------------------- | --------------------- | ------- | --------------------------------------- |
| `poise-accordion`      | `multiple`            | `false` | Allows more than one item to stay open. |
| `poise-accordion`      | `disabled`            | `false` | Disables every trigger.                 |
| `poise-accordion`      | `.value`              | `[]`    | Gets or sets the selected item values.  |
| `poise-accordion-item` | `value`               | —       | Identifies the item in the root value.  |
| `poise-accordion-item` | `open`                | `false` | Opens the item.                         |
| `poise-accordion-item` | `disabled`            | `false` | Disables the item's trigger.            |

Boolean attributes are enabled when present.

## Anatomy

### React

```text
Accordion          Base UI Accordion.Root
  AccordionItem      Base UI Accordion.Item
    AccordionTrigger Base UI Accordion.Header + Accordion.Trigger
    AccordionPanel   Base UI Accordion.Panel
```

### Web Component

```text
poise-accordion
  poise-accordion-item
    poise-accordion-trigger  role="button"
    poise-accordion-content  role="region"
```

The item links trigger and content with generated ARIA IDs.
The panel exposes its height as `--accordion-panel-height`.
