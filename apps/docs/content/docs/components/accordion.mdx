## Installation

<InstallCommand component="accordion" />

This copies `accordion.tsx` into your components directory, along with the
design tokens and the `cn` helper it depends on. Edit it in place.

## Usage

```tsx
import {
  Accordion,
  AccordionItem,
  AccordionPanel,
  AccordionTrigger,
} from "@/components/ui/accordion";

<Accordion defaultValue={["overview"]}>
  <AccordionItem value="overview">
    <AccordionTrigger>Overview</AccordionTrigger>
    <AccordionPanel>Panel content.</AccordionPanel>
  </AccordionItem>
</Accordion>;
```

`AccordionTrigger` renders the heading and the button together, so the pair
never has to be repeated by hand. Give every `AccordionItem` a `value` when you
want to control the accordion or set an initial open state.

## Staggered reveal

`AccordionPanel` takes a `reveal` prop. `stagger` fades the panel's children in
one after another instead of moving the panel as a single block.

<ComponentPreview name="accordion-stagger" />

The stagger runs on the panel's **element** children, so the content has to be
made of elements - paragraphs, list items, rows. A panel holding bare text has
nothing to stagger and falls back to the plain height transition.

Delays step 75ms apart and stop at the fifth child, so a long panel settles in
roughly half a second instead of growing without limit. Closing is never
staggered: the panel collapses as one, because reversing the ladder on the way
out feels slow. Under `prefers-reduced-motion`, the delays and the fade are
dropped.
