## Usage

### React

```tsx
import {
  Accordion,
  AccordionItem,
  AccordionPanel,
  AccordionTrigger,
} from "@/components/ui/accordion";

<Accordion defaultValue={["overview"]}>
  <AccordionItem value="overview">
    <AccordionTrigger>Overview</AccordionTrigger>
    <AccordionPanel>Panel content.</AccordionPanel>
  </AccordionItem>
</Accordion>;
```

`AccordionTrigger` renders the heading and the button together. Give every
`AccordionItem` a `value` to control the accordion or set an initial open
state.

## Options

### React

`AccordionPanel` takes one prop beyond Base UI's own.

| Prop     | Default  | Effect                                          |
| -------- | -------- | ----------------------------------------------- |
| `reveal` | `"none"` | `"stagger"` fades the panel's children in turn. |

<ComponentPreview name="accordion-stagger" />

The stagger runs on the panel's **element** children, so a panel holding bare
text has nothing to stagger and falls back to the plain height transition.
Delays step 75ms apart and stop at the fifth child. Closing is never staggered,
and under `prefers-reduced-motion` the delays and the fade are dropped.

### Web Component

| Element                | Attribute or property | Default | Effect                                  |
| ---------------------- | --------------------- | ------- | --------------------------------------- |
| `poise-accordion`      | `multiple`            | `false` | Allows more than one item to stay open. |
| `poise-accordion`      | `disabled`            | `false` | Disables every trigger.                 |
| `poise-accordion`      | `.value`              | `[]`    | Gets or sets the selected item values.  |
| `poise-accordion-item` | `value`               | —       | Identifies the item in the root value.  |
| `poise-accordion-item` | `open`                | `false` | Opens the item.                         |
| `poise-accordion-item` | `disabled`            | `false` | Disables the item's trigger.            |

Give every item a `value` when reading or setting the root's `.value` property.
Boolean options are HTML attributes, so their presence enables them.

## Anatomy

### React

```text
Accordion          Base UI Accordion.Root
  AccordionItem      Base UI Accordion.Item
    AccordionTrigger Base UI Accordion.Header + Accordion.Trigger
    AccordionPanel   Base UI Accordion.Panel
```

### Web Component

```text
poise-accordion
  poise-accordion-item
    poise-accordion-trigger  role="button"
    poise-accordion-content  role="region"
```

The item links its trigger and content with generated ARIA IDs. The content
measures its height, exposes it as `--accordion-panel-height`, and is hidden
only after its closing transition finishes.
