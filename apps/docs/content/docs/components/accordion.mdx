---
title: Accordion
description: A stack of headings that each reveal a panel of content.
---

<ComponentPreview name="accordion" />

## Usage

```tsx
import {
  Accordion,
  AccordionItem,
  AccordionPanel,
  AccordionTrigger,
} from "@/components/ui/accordion";

<Accordion defaultValue={["overview"]}>
  <AccordionItem value="overview">
    <AccordionTrigger>Overview</AccordionTrigger>
    <AccordionPanel>Panel content.</AccordionPanel>
  </AccordionItem>
</Accordion>;
```

`AccordionTrigger` renders the heading and the button together. Give every
`AccordionItem` a `value` to control the accordion or set an initial open
state.

## Options

`AccordionPanel` takes one prop beyond Base UI's own.

| Prop     | Default  | Effect                                          |
| -------- | -------- | ----------------------------------------------- |
| `reveal` | `"none"` | `"stagger"` fades the panel's children in turn. |

<ComponentPreview name="accordion-stagger" />

The stagger runs on the panel's **element** children, so a panel holding bare
text has nothing to stagger and falls back to the plain height transition.
Delays step 75ms apart and stop at the fifth child. Closing is never staggered,
and under `prefers-reduced-motion` the delays and the fade are dropped.

## Anatomy

```text
Accordion          Base UI Accordion.Root
  AccordionItem      Base UI Accordion.Item
    AccordionTrigger Base UI Accordion.Header + Accordion.Trigger
    AccordionPanel   Base UI Accordion.Panel
```
