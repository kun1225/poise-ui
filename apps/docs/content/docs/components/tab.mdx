title: Tab

<ComponentPreview name="tab" />

## Usage

```tsx
import { Tabs, TabsList, TabsPanel, TabsTrigger } from "@/components/ui/tab";

<Tabs defaultValue="overview">
  <TabsList>
    <TabsTrigger value="overview">Overview</TabsTrigger>
    <TabsTrigger value="settings">Settings</TabsTrigger>
  </TabsList>

  <TabsPanel value="overview">Overview panel content.</TabsPanel>
  <TabsPanel value="settings">Settings panel content.</TabsPanel>
</Tabs>;
```

## Options

`TabsTrigger` takes an icon; `Tabs` says how icons behave.

| Prop           | Default    | Effect                                   |
| -------------- | ---------- | ---------------------------------------- |
| `icon`         | —          | Node drawn beside the trigger's label.   |
| `icons`        | `"active"` | `"all"` shows every icon instead of one. |
| `iconPosition` | `"start"`  | `"end"` puts the icon after the label.   |
