---
title: Morph Accordion
description: A stack of rows that splits apart, so the open one becomes a card of its own.
---

<ComponentPreview name="morph-accordion" />

## Usage

```tsx
import {
  MorphAccordion,
  MorphAccordionItem,
  MorphAccordionPanel,
  MorphAccordionTrigger,
} from "@/components/ui/morph-accordion";

<MorphAccordion>
  <MorphAccordionItem value="overview">
    <MorphAccordionTrigger>Overview</MorphAccordionTrigger>
    <MorphAccordionPanel>Panel content.</MorphAccordionPanel>
  </MorphAccordionItem>
</MorphAccordion>;
```

The gap between rows is a transform, not a margin, so neighbouring rows move
**outside** the accordion's own box. Leave `1rem` of room above and below it,
or the effect will overlap whatever sits alongside.

## Options

`MorphAccordion` takes three props beyond Base UI's own.

| Prop        | Default | Effect                                                  |
| ----------- | ------- | ------------------------------------------------------- |
| `hasBorder` | `true`  | Divides rows that are both closed.                      |
| `depth`     | `false` | Pushes the rows that stayed closed into the background. |
| `gap`       | `16`    | Pixels a neighbouring row moves clear of the open one.  |

<ComponentPreview name="morph-accordion-plain" />

Turning `hasBorder` off only removes the divider between two closed rows. Every
edge where a card has to seal stays painted, so the stack starts as one blank
card and gains its seams as it splits. It resolves to a custom property, so it
can also be set through `className`:

```tsx
<MorphAccordion className="[--morph-divider:transparent]">
```

`depth` drops the closed rows to `0.96` scale, `0.65` opacity and `1.5px` of
blur. Those rows stay clickable while they are blurred, so keep it for stacks
whose closed rows are short labels.

## Anatomy

```text
MorphAccordion          Base UI Accordion.Root
  MorphAccordionItem      Base UI Accordion.Item
    MorphAccordionTrigger Base UI Accordion.Header + Accordion.Trigger
    MorphAccordionPanel   Base UI Accordion.Panel
```

Base UI decides when to unmount a panel by watching for a CSS transition, and
there is none here. `MorphAccordionPanel` therefore keeps its panel mounted and
marks it `inert` while closed, so Motion owns the exit and a closed panel still
stays out of the tab order and the accessibility tree.
