## Usage

### React

```tsx
import { Button } from "@/components/ui/button";

<Button variant="solid" size="md">
  Continue
</Button>;
```

### Web Component

```ts
import "@/components/ui/poise-button";
```

```html
<poise-button variant="solid" size="md">Continue</poise-button>
```

## API

| Prop       | Type                                                  | Default   |
| ---------- | ----------------------------------------------------- | --------- |
| `variant`  | `solid` `soft` `outline` `ghost` `danger`             | `solid`   |
| `size`     | `sm` `md` `lg`                                        | `md`      |
| `disabled` | `boolean`                                             | `false`   |

The React target additionally accepts every prop of Motion's `motion.button`,
so `whileHover`, `onClick` and the standard button attributes all pass through.

## Animation

Both targets use the `snappy` spring from the shared motion vocabulary:

```ts
export const springs = {
  snappy: { type: "spring", stiffness: 500, damping: 35 },
};
```

React applies it declaratively through Motion's `whileTap`. The Web Component
calls Motion's vanilla `animate()` on pointer events, and skips the animation
when `prefers-reduced-motion` is set.

## Accessibility

Both targets render a native `<button>` element, so keyboard activation, focus
order and screen reader semantics come from the platform.

<Callout>
The Web Component is not form-associated yet. A `type="submit"` button inside
the shadow root will not submit a surrounding form — that needs
`ElementInternals`, which is not implemented.
</Callout>
