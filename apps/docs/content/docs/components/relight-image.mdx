## Usage

First, create a depth image from your source image with the [Image Depth Generator](https://depth.fojcikdominik.com/).
Download the generated image, then pass its path to `depthSrc`.

```tsx
import { RelightImage } from "@/components/ui/relight-image";

<RelightImage
  src="/images/portrait.jpg"
  depthSrc="/images/portrait-depth.webp"
  alt="A portrait"
  className="aspect-3/2 w-full rounded-xl"
/>;
```

The source image and depth map must use the same dimensions and crop.
White depth pixels represent nearby surfaces. Black pixels represent distant surfaces.

The component keeps the source image beneath its canvas. That image remains visible when GPU rendering or depth loading fails.

Remote depth maps must allow cross-origin pixel access. Same-origin image paths require no additional configuration.

## Settings

Pass `settings` when the default lighting does not suit an image.

| Setting            | Default     | Effect                                      |
| ------------------ | ----------- | ------------------------------------------- |
| `lightColor`       | `#e1ded1`   | Point-light color.                          |
| `lightIntensity`   | `2.35`      | Point-light brightness.                     |
| `lightElevation`   | `0.9`       | Light distance above the image.             |
| `ambientIntensity` | `0.3`       | Base light across the image.                |
| `depthSmoothing`   | `1.3`       | Depth blur as a percentage of image width.  |
| `depthStrength`    | `4`         | Estimated depth range.                      |
| `normalStrength`   | `3`         | Lighting response from depth gradients.     |
| `detailStrength`   | `3`         | Fine normals derived from image brightness. |
| `shadowStrength`   | `0.86`      | Self-shadow opacity.                        |
| `shadowSoftness`   | `0.092`     | Self-shadow edge softness.                  |

```tsx
<RelightImage
  src="/images/portrait.jpg"
  depthSrc="/images/portrait-depth.webp"
  alt="A portrait"
  settings={{
    lightColor: "#ffe0bd",
    lightIntensity: 4,
    normalStrength: 1.5,
  }}
/>;
```

Set `interactive={false}` for fixed lighting. Reduced-motion preferences also disable pointer-driven lighting.

## Performance

The renderer caps pixel density at two. It also skips rendering while the component is outside the viewport.

Use a small number of visible instances. Each instance owns a renderer, canvas, textures, and GPU resources.

The technique follows Dominik Fojcik's [MIT-licensed Codrops demo](https://github.com/DGFX/codrops-relightning-images).
