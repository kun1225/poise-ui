poise-ui is a source-distributed component library.

The CLI copies component source into your project.
You own the files after installation.

Components use [Base UI](https://base-ui.com) for behavior and accessibility.
They use Tailwind and CSS tokens for styling.

## Getting started

Set up config and tokens:

```bash
npx poise-ui init
```

Add a component:

```bash
npx poise-ui add accordion
```

The CLI installs the component, its dependencies, and matching imports.

## How it fits together

```text
tokens      CSS custom properties on :root, mapped into Tailwind's theme
behaviour   Base UI primitives, wrapped thinly
styling     Tailwind classes composed with cn(), yours to change
```

Edit component classes for local styling.
Edit tokens for global styling.

<Callout>
  Only React components ship today. Web Components are planned.
</Callout>
