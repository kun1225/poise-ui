poise-ui is not an npm package you install. It is a registry of source files
that the CLI copies into your project, where you own and edit them.

Components are built on [Base UI](https://base-ui.com) for behaviour and
accessibility, and styled with Tailwind against a small set of design tokens.
Nothing is hidden behind a package boundary: the file that lands in your repo
is the whole component.

## Getting started

Set up the config and design tokens:

```bash
npx poise-ui init
```

Then add a component:

```bash
npx poise-ui add accordion
```

The CLI writes the component into your components directory, pulls in whatever
it depends on — tokens, the `cn` helper — and rewrites imports to match the
aliases you chose at init.

## How it fits together

```text
tokens      CSS custom properties on :root, mapped into Tailwind's theme
behaviour   Base UI primitives, wrapped thinly
styling     Tailwind classes composed with cn(), yours to change
```

Tokens stay plain CSS custom properties on `:root`, which Tailwind maps into
its theme with `@theme inline`. Restyling a component means editing its
classes; restyling everything means editing the tokens.
